# 網頁與鍵盤修正驗證（2026-10-12）

修正舊網頁固定連接 8766、右側滑桿被按鈕擠出畫面、新播放器未訂閱 Isaac 鍵盤的問題。新版使用同源 API、可捲動側欄與行動版頁面，並在站立待命時接受位置／輪速覆蓋。

Chrome 無頭瀏覽器連接獨立 Isaac 後端 8787，確認 26 個滑桿、390×844 畫面捲動、肘部目標實際作用、Release all、正反躺與 recovery 按鈕派送、Backflip 請求、W/A 指令與放開停止。這是控制連線驗證，不代表每個實驗 recovery 已成功起身。結果見 browser_result.json，截圖見 desktop.png 與 mobile.png。

另用真正有視窗的 Isaac 在 8788 執行 5 步，確認鍵盤訂閱與正常關閉；鍵盤事件與技能保護由 tests/test_skill_controls.py 驗證。此次沒有更換模型或重訓。

## WASD 倒下與後翻未啟動的後續修正

先前只驗證按鈕派送與命令送達，沒有充分涵蓋持續移動。此次重現舊整合版 8 個環境前進後全部倒下，後翻因此被站立條件拒絕。滑行／姿勢模型的輪速倍率應為訓練設定的 25，而非 recovery residual 使用的 8；已改用訓練常數及相同輪速裁切，並恢復舊播放器的加速、減速與轉向平滑。

原生 Isaac 空白鍵會暫停時間軸，已在 Kit 更新事件恢復播放，避免「停止移動」連同物理模擬一起停住。有視窗 Isaac 的實際暫停／恢復測試與 6 個控制單元測試通過。切換技能時也清除按住的原生移動鍵及命令目標，避免技能被後續指令干擾。

Backflip 準備從目前位置重新設定站立控制中心；起跳前另外確認實際輪速低於 1.2 rad/s，保留原有身體速度、姿態與關節條件。翻轉量改沿起跳朝向的水平側向軸累積，避免轉向後仍用世界 Y 軸造成觀測與落地判定錯誤。訓練環境未指定此軸時仍用原來的世界 Y 計算。模型、參考軌跡與致動器參數未更換；active runtime metadata 明確記錄控制程式變更並更新對應雜湊。

驗證結果見 motion_result.json。修正輪速後的 8 個環境皆通過持續前進、左右轉、倒退與煞停。單台機器人的完整移動停止後翻成功並保持收臂落地 6.12 秒；最終站立後翻保持 5.08 秒；實際轉向 1.35 rad（約 77°）後翻保持 3.32 秒。後兩者原始記錄見 idle_final.json 與 turn_final.json。這些是 seed 4107 的情境驗證，不代表所有物理參數下 100% 成功；原模型 holdout 成功率見既有訓練紀錄。

調整過的站立阻尼因變差而撤回；過窄的 pitch 閘門也曾造成準備逾時，最終保留原來 0.06 條件。motion_result.json 同時保留失敗與中間測試，避免把調整過程當成最終成功率。完整實體回歸可用 tests/verify_live_skill_motion.py；--drive-only --num_envs 8 驗證批次移動，--turn-only 驗證轉向後翻，預設驗證完整 WASD 與兩次後翻。使用 Isaac Python 並設定 WHEEL_HUMANOID_ROOT。
